Lean Video Analyser

SNCF Voyageurs · Python · OpenCV · Lean Management · 2026

Application Python de détection et tracking de personnes en temps réel depuis une vidéo de surveillance. Conçue pour automatiser les analyses Lean terrain.

Fonctionnalités clés :

  • Tracking multi-personnes — algorithme centroïde + NMS, ID unique par personne
  • Diagramme Spaghetti — trajectoires sur fond vidéo réel, export PNG
  • Heatmap de densité — zones chaudes identifiées instantanément
  • 7 graphes Mudas — évolution temporelle en temps réel
  • Export rapport — PDF complet KPIs + spaghetti + heatmap
  • 60 FPS — détection optimisée, thread UI découplé

Stack : Python 3.14 · OpenCV (MOG2) · NumPy · Matplotlib · Tkinter · Pillow
